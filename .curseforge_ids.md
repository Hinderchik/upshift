## Upload Commands
```powershell
# Upload to base project (1759097)
$metaJson = '{"changelog":"...","changelogType":"markdown","displayName":"...","releaseType":"beta","gameVersionNames":["Client","NeoForge","26.2"]}'
$metaFile = "$env:TEMP\cf-meta.json"
[System.IO.File]::WriteAllText($metaFile, $metaJson, [System.Text.UTF8Encoding]::new($false))
curl.exe -sS -X POST "https://minecraft.curseforge.com/api/projects/1759097/upload-file" `
    -H "X-Api-Token: $env:CF_API_TOKEN" `
    -F "metadata=<$metaFile;type=application/json" `
    -F "file=@<jar_path>;type=application/java-archive" `
    -w "`nHTTP_STATUS=%{http_code}"

# Upload to VR project (1797892) — same pattern, change project ID
curl.exe -sS -X POST "https://minecraft.curseforge.com/api/projects/1797892/upload-file" ...
```

# Upshift — Дорожная карта (roadmap)

Планируемые фичи, разделённые по блокам. Для каждой указана оценка сложности
(через реализацию пройдёт и Fabric, и NeoForge сборка). Порядок — предлагаемый
приоритет; финальный диктует пользователь.

## 1. Графика и рендер

### 1.1 Depth-aware TAAU / Reprojection — [средняя сложность]
**Суть:** сейчас репроекция и генерация кадров используют только гомографию по
повороту камеры (одно чтение текстуры, без глубины). Добавить чтение буфера
глубины в `taau_resolve` / `fgr_reproject`:
- восстанавливать мировые координаты пикселя через `inverse(projection)`;
- компенсировать трансляцию камеры (страйф, ходьба), а не только поворот;
- убрать гостинг при движении вперёд/вбок.

**Затрагивает:** `TaauPass`, `VrTaauPass`, `FrameGenPresenter`, `VrFrameGen`,
шейдеры `taau_resolve*.fsh`, `fgr_reproject*.fsh`, `screenquad.vsh`.

### 1.2 Адаптивный CAS (sharpening) отдельно от FSR — [низкая сложность]
**Суть:** дать игрокам на 100% scale (нативный рендер) возможность включить
только фильтр резкости (RCAS от AMD / sharpening от NIS) без понижения
разрешения.
- новое значение апскейлера/переключатель «Sharpening only»;
- RCAS-проход уже есть в `Fsr1Pass` — переиспользовать как пост-процесс без
  downscale;
- активен при `renderScale() == 1.0` и включённом sharpness.

**Затрагивает:** `Upscaler`, `UpscaleManager`, `SodiumConfigEntry` (оба лоадера).

### 1.3 Маска для частиц и прозрачности — [высокая сложность]
**Суть:** падающий снег/дождь, частицы факелов и полупрозрачная вода сильно
размазываются в TAAU и при генерации кадров.
- выносить частицы/прозрачные слои за проход апскейлинга ИЛИ исключать их из
  буфера истории (depth/opacity-маска);
- в FrameGen — исключать прозрачные слои из репроецируемого изображения.

**Затрагивает:** `GameRendererMixin`/`VrGameRendererMixin` (управление порядком
проходов), `TaauPass`, `FrameGenPresenter`.

## 2. Интеграция с другими модами

### 2.1 Iris Shaders — [средняя сложность, Fabric]
**Суть:** автодетектор активного шейдерпака. Если шейдерпак использует свой
temporal (TAA), Upshift:
- переключает апскейлер на пространственный (FSR 1 / NIS);
- отключает джиттер проекции, чтобы не было конфликта двух темпоральных пассов.

**Ограничение:** Iris — Fabric-only. На NeoForge интеграция не применяется
(детектор отключается без Iris).

**Затрагивает:** `Capabilities`/`UpscaleManager` (автосброс апскейлера),
детектор активного шейдерпака через Iris API или скан папки шейдерпаков.

### 2.2 Distant Horizons — [высокая сложность]
**Суть:** проверить совместимость репроекции и генерации кадров с буферами
Distant Horizons (LOD-чанки), чтобы дальние LOD не дёргались при повороте
камеры.
- понять, как DH встраивается в рендер-цикл 26.2;
- при конфликте — отключать темпоральный апскейлинг для LOD-прохода.

**Затрагивает:** `GameRendererMixin`, `FrameGenPresenter`, шейдеры.

## 3. Оптимизации и UX

### 3.1 Пресеты «в один клик» — [низкая сложность]
**Суть:** вынести профили (`PerfProfile`) вверх вкладки как понятный
переключатель: «Картошка / Ноутбук / Баланс / Качество», чтобы новичку не
пришлось разбираться в процентах масштаба и резкости.
- профиль уже применяется в `UpscaleManager.beginWorld` / `CpuTuner.apply`;
- нужно лишь вынести виджет выше по порядку в Sodium-меню.

**Затрагивает:** `SodiumConfigEntry` (оба лоадера).

### 3.2 Горячая клавиша сравнения (toggle / split-screen) — [средняя сложность]
**Суть:** клавиша в настройках управления, которая в игре:
- мгновенно включает/выключает апскейлинг, ИЛИ
- делит экран пополам (слева натив, справа апскейл) для сравнения.

Toggle — просто; split-screen — сложнее (два рендер-таргета на экране).
Начать с toggle.

**Затрагивает:** `UpshiftClient`/`UpshiftNeoForge` (регистрация keybind),
`UpscaleManager` (флаг паузы).

### 3.3 Whitelist для заморозки анимаций — [низкая сложность]
**Суть:** опция «Freeze animations when unfocused» замораживает все анимации
текстур (`TextureAtlas.tick`). На технических сборках (Create и конвейеры)
это мешает. Добавить белый список блоков/модов, чьи анимации не замораживать.

**Затрагивает:** `TextureAtlasMixin`, `FsrConfig` (список), `SodiumConfigEntry`.

## Приоритет (предлагаемый порядок реализации)

1. **3.3 Whitelist анимаций** — низкая сложность, быстрый выигрыш UX.
2. **1.2 Адаптивный CAS** — низкая сложность, полезно многим игрокам.
3. **3.1 Пресеты в один клик** — низкая сложность, улучшение меню.
4. **3.2 Горячая клавиша (toggle)** — средняя сложность, заметная фича.
5. **2.1 Iris автодетектор** — средняя сложность, Fabric.
6. **1.1 Depth-aware TAAU** — средняя сложность, качество картинки.
7. **2.2 Distant Horizons** — высокая сложность.
8. **1.3 Маска частиц/прозрачности** — высокая сложность.

Каждая фича реализуется в обеих сборках (Fabric + NeoForge), кроме Iris
(Fabric-only). Изменения вносятся в оба `src/main/...` дерева синхронно.
